Process Visualization

Pseudo Code

This pseudo-code outlines the four main events in the JavaScript which are starting the game, checking the round, starting a round, and ending the game. Start Game establishes the player and round number counts and calls the Check Round. Check Round checks whether to start a new round or end the game based on current round number. Start Round starts the gameplay and determines the amount of points earned by players, then calls the Check Round. End Game checks the player scores and establishes a winner; or a draw if the scores are tied.
